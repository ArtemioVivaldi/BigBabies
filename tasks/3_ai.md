# Частина 3 — ШІ (`ai_writer.py`)

**Твій файл:** `ai_writer.py`. Інші файли не змінюєш.
**Твоя роль:** перетворити цифри з `summary` на коротку теплу історію для батьків.
**Від кого залежиш:** формально від аналітики, але стартуєш одразу на `data/samples/summary_2025.json`.
**Хто залежить від тебе:** інтерфейс (він стартує на `data/samples/story_2025.md`).

Перед стартом прочитай: `PROJECT.md`, розділ 3 у `CONTRACTS.md`, приклади
`data/samples/summary_2025.json` (вхід) і `data/samples/story_2025.md` (який вигляд має мати результат).

## Підготовка (ще до хакатону!)

1. Отримати безкоштовний ключ API: **Google AI Studio** (Gemini) — основний варіант;
   **console.groq.com** (Groq) — запасний. Безкоштовні ліміти невеликі, тому програма має робити 1 запит на одну історію.
2. Скопіювати `.env.example` → `.env`, вписати ключ. Перевірити, що ключ працює (у самому AI Studio / Groq console).
3. Мати запасний ключ з іншого акаунта.

## Запит до API через `requests` (без додаткових бібліотек)

**Gemini** (`LLM_PROVIDER=gemini`):
```
POST https://generativelanguage.googleapis.com/v1beta/models/<LLM_MODEL>:generateContent?key=<LLM_API_KEY>
Тіло:     {"contents": [{"parts": [{"text": "<промпт>"}]}]}
Відповідь: r.json()["candidates"][0]["content"]["parts"][0]["text"]
```

**Groq** (`LLM_PROVIDER=groq`, формат як у OpenAI):
```
POST https://api.groq.com/openai/v1/chat/completions
Заголовок: Authorization: Bearer <LLM_API_KEY>
Тіло:     {"model": "<LLM_MODEL>", "messages": [{"role": "user", "content": "<промпт>"}]}
Відповідь: r.json()["choices"][0]["message"]["content"]
```

Назви моделей змінюються — актуальну безкоштовну модель візьми в AI Studio / Groq console під час підготовки
і впиши в `.env`. Завжди став `timeout=30`.

## Вимоги до промпта

У промпт передаємо **лише готові цифри** з `summary` (назва школи, рік, загальна сума, категорії з частками,
топ-5, найдорожчий місяць, найдешевша покупка, сума на день). Просимо:
- українська мова, 120–200 слів, Markdown, заголовок з емодзі, 3–5 коротких абзаців;
- писати для батьків, без бюрократичних слів («закупівля послуг їдалень» → «обіди для дітей»);
- **використовувати лише надані цифри, нічого не вигадувати і не оцінювати** (не писати «переплатили», «корупція»);
- суми округлювати по-людськи: 2 826 250 → «2,83 млн грн»;
- останній рядок: *«За даними оголошених закупівель у системі Prozorro.»*
