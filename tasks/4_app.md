# Частина 4 — Інтерфейс, інтеграція і презентація (`app.py`)

**Твій файл:** `app.py` (а також `README.md` і слайди). Модулі інших не змінюєш.
**Твоя роль:** зібрати все в один застосунок, провести інтеграцію і підготувати демо.
**Від кого залежиш:** від усіх, але до 1:30 працюєш на прикладах з `data/samples/`.

Перед стартом прочитай: `PROJECT.md`, весь `CONTRACTS.md`, приклади `data/samples/summary_2025.json` і `data/samples/story_2025.md`.

## Як виглядає сторінка (зверху вниз)

1. Заголовок «Гроші моєї школи» + один рядок пояснення.
2. Поле пошуку → список знайдених установ (`st.selectbox`) → вибір року (`st.selectbox` з `available_years`).
3. Картки-метрики (`st.metric`): загальна сума, кількість закупівель, сума на день.
4. Історія від ШІ (`st.markdown`).
5. Графік за категоріями (`st.bar_chart`) і графік по місяцях.
6. Таблиця «Топ-5 покупок» з посиланнями на Prozorro: `https://prozorro.gov.ua/tender/<tender_id>`.
7. Підвал: джерело даних, примітка «очікувана вартість».

## Порада щодо інтеграції

Поки модулі не готові, тримай у `app.py` дві функції-«перемикачі», щоб перехід був одним рядком:

- на старті: summary читається з `data/samples/summary_2025.json`, історія — з `story_2025.md`;
- після 1:30: `build_summary(get_tenders(edrpou), year)` і `write_story(summary)`.

## Структура презентації

1. **Проблема:** дані про витрати шкіл відкриті, але звичайна людина в них не розбереться.
2. **Що є зараз:** DOZORRO, BI Prozorro — для експертів і пошуку порушень.
3. **Наше рішення:** «Spotify Wrapped» для бюджету школи — просто, наочно, для батьків.
4. **Демо** (живе): пошук школи → підсумки → історія від ШІ. Запасний план — школа з кешу.
5. **Як це працює:** Prozorro → Python рахує → ШІ пояснює (схема з 4 модулів).
6. **Що далі:** порівняння шкіл міста, посилання для батьківського чату, інші установи.
