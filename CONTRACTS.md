## 0. Джерело даних: пошуковий API сайту prozorro.gov.ua

API внутрішній (ним користується сам сайт), документації немає. Перевірено вручну 15.11.2026.

**Обов'язково** передавати заголовок браузера, інакше запит блокується:

```python
HEADERS = {"User-Agent": "Mozilla/5.0"}
```

### 0.1 Пошук установи за назвою

```
POST https://prozorro.gov.ua/api/search/organizations?type=buyer&value=<текст>
```

Відповідь (приклад: `data/samples/raw_organizations.json`):

```json
{"page": 0, "per_page": 15, "total": 2139,
 "data": [{"name": "початкова школа \"школа радості\" львівської міської ради",
           "id": "22416862", "buyer": true, "tenderer": true}]}
```

`id` — це код ЄДРПОУ установи.

### 0.2 Закупівлі установи

```
POST https://prozorro.gov.ua/api/search/tenders?buyer[0]=<ЄДРПОУ>&page=<N>
```

- сторінки по 20 записів, нумерація з **1** (`page=0` і `page=1` повертають те саме)
- закупівлі відсортовані від нових до старих
- максимум 50 сторінок (1000 записів), далі `data` порожній
- коли `data` порожній — сторінки закінчилися

Відповідь (приклад: `data/samples/raw_search_page.json`):

```json
{"page": 1, "per_page": 20, "total": 437,
 "data": [{
   "procuringEntity": {"name": "ПОЧАТКОВА ШКОЛА \"ШКОЛА РАДОСТІ\" ...",
                       "identifier": {"legalName": "..."},
                       "address": {"locality": "місто Львів"}},
   "tenderID": "UA-2026-09-08-000070-a",
   "title": "Технічний нагляд ... 71240000-2 Архітектурні, інженерні та планувальні послуги",
   "value": {"amount": 14866, "valueAddedTaxIncluded": false, "currency": "UAH"},
   "status": "complete"}]}
```

Важливо знати:
- `value.amount` — **очікувана вартість** закупівлі. Фактична сума договору може трохи відрізнятися. На презентації так і кажемо: «за даними оголошених закупівель».
- Окремого поля з датою немає — дата закодована в `tenderID`: `UA-2026-09-08-000070-a` → 8 вересня 2026.
- Код класифікатора ДК 021 (CPV) у вигляді `55510000-8` часто є в тексті `title`.

## 1. Модуль даних → `data_loader.py`

### `search_schools(query: str) -> list[dict]`

Повертає список установ (порожній список, якщо нічого не знайдено):

```json
[{"name": "початкова школа \"школа радості\" львівської міської ради", "edrpou": "22416862"}]
```

### `get_tenders(edrpou: str, use_cache: bool = True) -> dict`

Повертає **всі** закупівлі установи в нормалізованому вигляді:

```json
{
  "school": {"name": "ПОЧАТКОВА ШКОЛА \"ШКОЛА РАДОСТІ\" ЛЬВІВСЬКОЇ МІСЬКОЇ РАДИ",
             "edrpou": "22416862",
             "city": "місто Львів"},
  "tenders": [
    {
      "tender_id": "UA-2025-01-16-018720-a",
      "title": "«Послуги з організації шкільного харчування» ДК 021:2015 55510000-8 Послуги їдалень",
      "amount": 2826250.0,
      "currency": "UAH",
      "vat_included": false,
      "status": "complete",
      "date": "2025-01-16",
      "year": 2025,
      "month": 1,
      "cpv": "55510000-8"
    }
  ]
}
```

Правила нормалізації:
| Поле | Звідки | Примітка |
|---|---|---|
| `tender_id` | `tenderID` | без змін |
| `title` | `title` | переноси рядків і подвійні пробіли → один пробіл, `strip()` |
| `amount` | `value.amount` | завжди `float` |
| `currency` | `value.currency` | |
| `vat_included` | `value.valueAddedTaxIncluded` | |
| `status` | `status` | без змін |
| `date`, `year`, `month` | з `tenderID` | `UA-РРРР-ММ-ДД-...` |
| `cpv` | з `title` | регулярний вираз `(\d{8}-\d)`, перший збіг; якщо немає — `null` (`None`) |
| `school.city` | `procuringEntity.address.locality` першого запису | якщо немає — `""` |

Кеш: результат `get_tenders` зберігається у `data/<ЄДРПОУ>.json` **саме в цьому форматі**
(`json.dump(..., ensure_ascii=False, indent=2)`). Якщо `use_cache=True` і файл є — читаємо файл, мережу не чіпаємо.
Якщо мережа недоступна, а кешу немає — кидаємо `ConnectionError` з людським повідомленням.

## 2. Модуль аналітики → `analysis.py`

### `CATEGORIES` — фіксований список категорій (порядок важливий для графіків)

```python
CATEGORIES = [
    "Харчування",
    "Комунальні послуги",
    "Ремонт і будівництво",
    "Техніка, зв'язок і програми",
    "Меблі, обладнання і товари",
    "Обслуговування і безпека",
    "Інше",
]
```

### `categorize(tender: dict) -> str`

Повертає одну з `CATEGORIES` за кодом `cpv` (правила — у `tasks/2_analysis.md`).

### `available_years(tenders: list[dict]) -> list[int]`

Роки, за які є хоч одна закупівля, від нових до старих: `[2026, 2025, ...]`.

### `build_summary(data: dict, year: int) -> dict`

Приймає результат `get_tenders(...)` і рік. Враховує **лише** закупівлі з `status == "complete"`.
Повертає словник (повний приклад: `data/samples/summary_2025.json`):

```json
{
  "school": {"name": "...", "edrpou": "22416862", "city": "місто Львів"},
  "year": 2025,
  "total_amount": 9491914.0,
  "tenders_count": 54,
  "by_category": [
    {"category": "Харчування", "amount": 5055403.0, "count": 5, "share": 0.5326}
  ],
  "top_purchases": [
    {"tender_id": "UA-2025-01-16-018720-a", "title": "...", "amount": 2826250.0,
     "date": "2025-01-16", "category": "Харчування"}
  ],
  "by_month": [{"month": 1, "amount": 4065168.05}],
  "facts": {
    "biggest":  {"tender_id": "...", "title": "...", "amount": 2826250.0, "date": "...", "category": "..."},
    "smallest": {"tender_id": "...", "title": "...", "amount": 987.79,    "date": "...", "category": "..."},
    "busiest_month": {"month": 1, "amount": 4065168.05},
    "per_day": 26005.24
  },
  "uncategorized_titles": ["назви закупівель з категорією «Інше»"]
}
```

Правила:
- `by_category` — лише категорії, де є хоч одна закупівля, від більшої суми до меншої; `share` — частка від `total_amount` (0..1, 4 знаки).
- `top_purchases` — 5 найдорожчих (або менше, якщо закупівель менше 5).
- `by_month` — **завжди 12 елементів** (місяці 1..12), навіть якщо сума 0.
- `per_day` — `total_amount / 365`.
- усі суми округлені до 2 знаків.
- якщо за рік немає жодної завершеної закупівлі — `total_amount = 0`, `tenders_count = 0`, списки порожні, `by_month` з нулями, `facts = None`.

## 3. Модуль ШІ → `ai_writer.py`

### `write_story(summary: dict) -> str`

Приймає `summary` з п. 2. Повертає текст українською (Markdown, 120–200 слів) — «підсумки року» для батьків.
Приклад: `data/samples/story_2025.md`.
**Ніколи не кидає помилку**: якщо ШІ недоступний (немає ключа, ліміт, немає інтернету) — повертає текст, зібраний за шаблоном із тих самих цифр.

### `classify_titles(titles: list[str]) -> dict[str, str]` (необов'язково, якщо буде час)

Для назв з `uncategorized_titles` повертає `{назва: категорія}`, де категорія — одна з `CATEGORIES`.
Один запит до ШІ на весь список. При помилці повертає `{}`.

Налаштування — у файлі `.env` (шаблон: `.env.example`), читаються через `python-dotenv`.
