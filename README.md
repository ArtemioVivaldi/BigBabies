# 🎒 Гроші моєї школи

**Підсумки року для бюджету школи — простою мовою, на відкритих даних Prozorro.**

Введіть назву школи (садочка, лікарні — будь-якої установи), оберіть рік і дізнайтеся:
скільки грошей установа витратила, на що саме, які були найбільші покупки — і прочитайте коротку
історію, яку на основі цих цифр пише штучний інтелект.

> Проєкт створено на хакатоні з основ програмування (тема — OpenData).

## Навіщо

Усі закупівлі державних і комунальних установ в Україні публічні — їх видно в системі Prozorro.
Але звичайній людині складно в них розібратися. Існуючі інструменти (DOZORRO, BI Prozorro) створені
для експертів і пошуку порушень. Ми робимо інше: **пояснюємо** витрати так, щоб це зрозуміли батьки.

## Як це працює

```
prozorro.gov.ua ──► data_loader.py ──► analysis.py ──► ai_writer.py ──► app.py (Streamlit)
  відкриті дані      завантаження        підрахунки       історія від ШІ     сторінка
                     + кеш               і категорії
```

Усі цифри рахує Python. ШІ лише переказує готові цифри людською мовою — тому він не може «вигадати» суми.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env          # впишіть ключ API для ШІ (необов'язково)
streamlit run app.py
```

Без ключа ШІ застосунок теж працює — історія збирається за шаблоном.

## Дані

- Джерело: [Prozorro](https://prozorro.gov.ua) — система публічних закупівель України.
- Суми — **очікувана вартість** оголошених закупівель; фактичні суми договорів можуть дещо відрізнятися.
- Враховуються лише завершені закупівлі.
