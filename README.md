# 💸 Куди пішли гроші вашої установи

**Підсумки року для бюджету будь-якої державної чи комунальної установи — простою мовою, на відкритих даних Prozorro.**

Введіть назву школи, садочка, лікарні, університету чи міської ради, оберіть її зі списку — і побачите,
скільки грошей установа витратила, на що саме, коли, які були найбільші покупки і як це змінювалось із роками.
Коротку історію з цих цифр пише штучний інтелект.

> Репозиторій **BigBabies**. Проєкт створено на хакатоні з основ програмування (тема — OpenData).

## Навіщо

Усі закупівлі державних і комунальних установ в Україні публічні: їх видно в системі [Prozorro](https://prozorro.gov.ua).
Але звичайній людині складно в них розібратися. Наявні інструменти (DOZORRO, BI Prozorro) створені
для експертів і пошуку порушень. Ми робимо інше: **пояснюємо** витрати так, щоб їх зрозуміли батьки, учні й жителі громади.
Ми не шукаємо корупцію й нікого не оцінюємо, лише показуємо, куди йдуть гроші.

## Що вміє сайт

- **Пошук із підказками:** починаєте вводити назву, і список установ оновлюється одразу (кнопка «×» очищає поле).
- **Три головні цифри** за обраний рік: скільки витрачено, скільки закупівель, скільки грошей щодня.
- **Історія від ШІ** у кілька абзаців, з позначкою, хто її написав.
- **Витрати за весь час:** багатошаровий графік по місяцях за всі роки, що є в Prozorro. Кожна закупівля окремий шар, плавний тренд,
  пунктир зі «звичайним» рівнем. Рамку можна рухати й розтягувати, щоб обрати період: одразу видно суму, мінімум і максимум.
- **На що пішли гроші:** розподіл за категоріями (харчування, комунальні послуги, ремонт і будівництво тощо) та витрати по місяцях.
- **Порівняння з минулим роком** за ті самі місяці, крива накопичення, зміни по категоріях.
- **Дрібні й великі покупки:** скільки закупівель і скільки грошей припадає на кожен розмір, частка п'яти найбільших закупівель.
- **Теплова карта** «категорія × місяць».
- **Топ-5 найбільших покупок** із посиланнями на оригінали в Prozorro.
- Світла й темна тема (за налаштуванням системи або перемикачем).

## Як це працює

```
prozorro.gov.ua ──► data_loader.py ──► analysis.py ──► api.py ──► web/ (HTML + JS)
  відкриті дані      завантаження        підрахунки       JSON        сайт у браузері
                     + кеш у data/       і категорії       ▲
                                                           └── ai_writer.py (історія від ШІ)
```

**Усі цифри рахує Python. ШІ лише переказує готові цифри людською мовою,** тому вигадати суми він не може.
Якщо ШІ недоступний, історія збирається за шаблоном із тих самих цифр, і сайт це чесно показує.

## Запуск

Потрібен Python 3.10 або новіший.

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # потім вписати ключ для ШІ (див. нижче), без нього теж працює
python api.py
```

Відкрийте в браузері **http://localhost:8000**.

Швидкий запуск подвійним кліком (сервер і браузер відкриваються самі): `run_demo.command` на macOS, `run_demo.bat` на Windows.
Вони беруть віртуальне середовище `.venv`, якщо воно є.

### Штучний інтелект: як він підключається

Історії пише Google Gemini. Є два способи, перший має пріоритет:

1. **Свій ключ** у файлі `.env` (він ніколи не потрапляє в git). Створіть ключ безкоштовно на aistudio.google.com:

   ```
   LLM_PROVIDER=gemini
   LLM_API_KEY=ваш_ключ_з_Google_AI_Studio
   LLM_MODEL=gemini-3.5-flash-lite
   ```

2. **Посередник** (папка `proxy/`): маленький сервер, де лежить спільний ключ. Адреса посередника прописана в `ai_writer.py`
   (`DEFAULT_PROXY_URL`), тому після `git clone` усе працює без жодного налаштування й без ключа. Як його розгорнути, дивіться `proxy/README.md`.

Без ключа й без посередника сайт теж працює, але історія збирається за шаблоном, і сайт це показує.

- Моделі `gemini-2.5-*` для нових ключів уже недоступні (помилка 404), а нові моделі 3.x не приймають параметр `thinkingBudget`,
  тому код шле його лише моделям 2.5.
- Перевірити власний ключ: `python -c "import ai_writer as a; print(a._ask_llm('Скажи привіт одним словом'))"`.
- **Ключ у git не коммітимо:** репозиторій публічний, Google автоматично відкликає ключі, знайдені на GitHub.

## Історії від ШІ: кеш і повтори

- Google часто відповідає помилкою 503 («висока навантаженість»), а модель іноді обриває текст. Тому `api.py` пробує до 4 разів
  із паузою й приймає лише завершену історію (з останнім рядком про джерело).
- Вдала історія зберігається у `data/stories/<ЄДРПОУ>_<рік>.md` і далі читається з файлу: це швидко й не залежить від Google.
  Шаблонна історія в кеш не пишеться. Щоб перегенерувати історію, видаліть її файл.
- **Перед демо** відкрийте потрібні установи заздалегідь, щоб історії вже лежали в кеші.

## Дані

- Джерело: [Prozorro](https://prozorro.gov.ua), система публічних закупівель України (відкриті дані).
- Суми це **очікувана вартість** оголошених закупівель; фактичні суми договорів можуть відрізнятися.
- Враховуються лише завершені закупівлі (статус `complete`). Для довідки показуємо й скільки закупівель скасовано чи не відбулося.
- Усі закупівлі установи завантажуються один раз і зберігаються в `data/<ЄДРПОУ>.json`; далі сайт працює з цього кешу, мережа не потрібна.
  Prozorro віддає не більше 1000 останніх закупівель на установу й обмежує частоту запитів (429), тому завантаження ввічливе, із паузами.
- **Категорії** визначаються за кодом CPV із назви закупівлі. Коли коду немає, категорію підбираємо за ключовими словами
  в назві (наприклад, «ремонт», «опалення», «капуста», «реактиви»). Це евристика, а не точна класифікація; медичні товари
  віднесено до «Меблі, обладнання і товари», бо окремої категорії для медицини немає.

## Структура репозиторію

| Файл або папка | Що робить |
|---|---|
| `data_loader.py` | пошук установ і завантаження закупівель із Prozorro, кеш у `data/` |
| `analysis.py` | категорії, роки, підсумки (`build_summary`) |
| `ai_writer.py` | історія від ШІ (`write_story`): власний ключ або посередник, запасна шаблонна історія |
| `proxy/` | посередник для ШІ (Cloudflare Worker), на якому лежить ключ, щоб його не було в git |
| `api.py` | JSON-бекенд (лише стандартна бібліотека): `/api/search`, `/api/summary`, віддає сайт із `web/` |
| `web/` | сайт: `index.html`, `style.css`, `app.js` (звичайний JavaScript, графіки на чистому SVG) |
| `data/` | кеші закупівель установ, кеш історій (`stories/`), приклади (`samples/`) |
| `CONTRACTS.md`, `PROJECT.md`, `tasks/` | договір між модулями й інструкції команди |

Модулі `data_loader.py`, `analysis.py` та `ai_writer.py` можна запускати окремо (`python analysis.py`), щоб перевірити їхню частину.

## Демо за 3 хвилини

1. Відкрити сайт, коротко сказати, що це і для кого (хвилина проблеми: дані відкриті, але нечитабельні).
2. Ввести «лікарня» або «гімназія», вибрати установу зі списку: показати три цифри й історію від ШІ.
3. Прокрутити до графіка **«Витрати за весь час»**, зсунути рамку на інший період.
4. Показати категорії, порівняння з минулим роком і топ-5 із посиланнями на Prozorro.
5. Сказати про чесність: цифри рахує програма, ШІ лише переказує, а суми це очікувана вартість.

Для демо добре підходять установи з довгою історією (наприклад, садочок №66 у Житомирі, Шосткинська дитяча лікарня,
Таврійський університет, Ліцей №272, Вінницька гімназія №24). Їх варто відкрити заздалегідь.
