# Посередник для ШІ (Cloudflare Worker)

Щоб кожен, хто завантажив проєкт із git, **одразу** мав історії від ШІ, а ключ **не лежав у репозиторії**
(він публічний, а Google автоматично відкликає ключі, знайдені на GitHub), ключ зберігається на цьому маленькому сервері.
Сайт (`ai_writer.py`) надсилає сюди промпт і отримує текст історії.

```
сайт на комп'ютері ──► посередник (Cloudflare Worker, ключ тут) ──► Google Gemini
```

Власний ключ у `.env` має пріоритет: якщо він є, сайт звертається до Google напряму. Посередник потрібен лише тим, хто ключа не має.

## Що робить посередник і як захищений

- Приймає лише `POST` з JSON `{"prompt": "..."}`; промпт має бути нашого формату (містить маркер із `build_prompt`) і не довший за 8000 символів.
- Модель і довжина відповіді зафіксовані в `worker.js`, тож використати його як універсальний чат не вийде.
- Простий ліміт: 30 запитів на хвилину з однієї адреси (приблизний, у пам'яті).
- Ключ береться з секрету Cloudflare `GEMINI_API_KEY`, у коді його немає.

## Розгортання (один раз, ~5 хвилин)

Потрібні безкоштовний акаунт [Cloudflare](https://dash.cloudflare.com/sign-up) і Node.js. Команди виконує власник ключа.

```bash
cd proxy
npx wrangler login                      # відкриє браузер: увійдіть в Cloudflare
npx wrangler secret put GEMINI_API_KEY  # вставте ключ із Google AI Studio (воно його не покаже й не збереже в git)
npx wrangler deploy                     # у кінці надрукує адресу: https://bigbabies-ai.<ваш-субдомен>.workers.dev
```

(Якщо Node встановлено в `~/.local/node`, додайте перед командами `PATH=$HOME/.local/node/bin:$PATH`.)

Потім:

1. Скопіюйте надруковану адресу в `DEFAULT_PROXY_URL` у файлі `ai_writer.py` (адреса не секретна, її можна комітити).
2. Закомітьте й запуште. Відтепер після `git clone` і `python api.py` ШІ працює без жодних налаштувань.

## Перевірка

```bash
curl -s -X POST https://ВАША-АДРЕСА.workers.dev -H 'Content-Type: application/json' -d '{"prompt":"тест"}'
# очікуємо {"error":"Невірний промпт"}: сервер живий і відсікає зайве
```

## Безпека ключа

- Після події (презентації) **видаліть ключ** у Google AI Studio або випустіть новий і оновіть секрет командою вище.
- У Google AI Studio можна обмежити квоту ключа, щоб його не вичерпали.
- Не коммітьте `.env`: він у `.gitignore`.
